# EIproject
This project showcases various design patterns in software development, specifically focusing on behavioral, creational, and structural patterns.
The aim is to provide practical examples that illustrate how these patterns can be implemented in real-world scenarios.
## Behavioral Design Patterns
This section demonstrates two behavioral design patterns: **Observer** and **Strategy**.
## Creational Design Patterns
This section demonstrates two creational design patterns: **Singleton** and **Factory Method**.
## Structural Design Patterns
This section demonstrates two structural design patterns: **Adapter** and **Decorator**.
##MarsRoverProgramming
This project simulates a Mars Rover navigating a grid-based terrain. The Rover can move forward, turn left, and turn right while avoiding obstacles and staying within the grid boundaries. The implementation emphasizes pure Object-Oriented Programming (OOP) principles and design patterns, avoiding the use of if-else conditional constructs.
## Problem Statement
The goal of this exercise is to create a simulation for a Mars Rover that can navigate a defined grid. The Rover should be able to:
- Initialize with a starting position (x, y) and direction (N, S, E, W).
- Execute commands to move forward, turn left, and turn right.
- Detect obstacles and refrain from moving into them.
- Optionally, send a status report of its current position and facing direction.
